# 可选内容协作目录

这里保留外部Skill目录和内容流程参考，主工作台的安装、配置、能力与边界只在根README维护。

`a_class_repositories.json` 列出可选外部项目及建议目录；不会随本项目安装、克隆或执行它们。各项目保留自己的仓库与许可证，先审阅其SKILL和依赖，再在明确授权的任务中使用。

主工作台的研究、内容生成、本地排版、原生预览及数据回收不依赖这份目录，也不要求每篇稿件机械串行调用全部模块。已有独立外部仓库可用以下只读验证器检查目录完整性：

```text
python scripts/verify_a_class_skills.py <外部仓库集合目录>
```

归档压缩包、私人安装快照和上游完整源码没有打包进公开仓库。工作流参考不是发布权限，也不保证外部仓库长期可用、可构建或适合所有写作任务。

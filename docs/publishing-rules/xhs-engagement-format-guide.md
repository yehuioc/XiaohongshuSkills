# 指标与格式参考

本文件不附带任何真实帖子或账号数据，也不把私人样本统计写成普遍规律。

浏览、赞、收藏、评论、分享和曝光不是同一指标。只有平台实际取得的值才能记录；缺失保持未知，历史快照保留观察时间，不倒填为当前效果。

以笔记ID、账号、审核状态和可见范围关联观察，不只按标题匹配。已发布不等于公开，缺少私密标签也不证明公开。部分加载的列表不称账号全量；评论样本不称全部评论。

比较内容时先检查主题、时间、受众、样本选择和媒体差异。高互动相关性不足以证明某种标题、文体、发布时间或工具导致传播效果。避免把一次样本的观察自动变成永久写作规则。

自检：指标名称与来源是否一致，缺失值是否误记为零，覆盖范围与时间是否清楚，审核和公开状态是否混淆，是否将相关当成因果。

# 内容创作参考

本文件是通用编辑参考，不是平台硬性规范或传播效果保证。实际长度、媒体格式与发布声明以当前编辑器为准。

先确定读者问题和本篇判断，再选择可追溯材料。标题应准确表达内容，不夸大结果或制造虚假紧迫感。正文保留具体动作、条件、例子及限制，不编造个人经历、数字、评论或岗位真实性。

参考文案只迁移表达习惯，不迁移其经历和事实。图片、引用和摘要保留来源，未取得的正文／评论／图片分别说明，列表卡片不算完成精读。

图文包含标题、正文、话题及实际媒体；预览前核对账号、版本、媒体顺序、完整文字与设置。原生文字配图短文和完整发布文案分别管理。正式发布需要本篇明确确认，不能因生成通过或目录流程建议而获得授权。

自检：是否有明确读者与判断，事实是否可追溯，是否虚构经历，标题与正文是否一致，媒体是否实际生成，限制是否保留，是否取得本篇发布授权。

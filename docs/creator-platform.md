# 创作者平台说明

本项目通过用户绑定并开启接管的Chrome标签页检查创作者平台，不复制Cookie、不调用私有发布接口，也不接受任意脚本。页面结构会变更，以下描述当前适配与验证边界。

## 固定检查与导航

- `browser(operation=creator_inspect)`：读取当前账号、页面、已加载控件、笔记与草稿标识、限制和覆盖范围。
- `browser(operation=creator_navigate,target=...)`：固定的笔记管理、状态页、发布类型、草稿类型、只读搜索、菜单检查与关闭操作。
- 导航点击不等于实际到达，后续须重新检查。已有正文、媒体或原生写作区时拒绝普通导航，不覆盖未知草稿。
- 笔记管理以稳定ID关联观察，不只按标题匹配；搜索可能切换到“已发布”，清空搜索不等于切回“全部”。

## 四类内容

| 类型 | 当前确认的链路与限制 |
| --- | --- |
| 图文 | 图片进入原生编辑器、标题／正文与预览、存稿；原生文字配图短文合计500字符，完整正文独立。图片格式、数量、大小以当时页面提示为准。 |
| 视频 | 视频进入编辑器、默认封面、章节入口、预览与存稿；章节受视频时长限制，封面工具与上传入口分别核对。 |
| 长文 | 富文本、一键排版、分页文字核对、进入最终编辑器与存稿；长文源稿和最终短发布文案是两个字段，不能混写。 |
| 播客 | 音频上传、必填封面、进入最终编辑器与存稿；平台当前要求音频10分钟至2小时，发布设置仍须逐项核对。 |

草稿可能存于当前浏览器本地；它不是工作台SQLite，也不是已验证的跨设备备份。离开后是否保存必须在草稿箱按ID检查，不以“离开成功”代替存稿结果。

## 设置与封面

可见范围与内容类型声明通过原生Select交互。平台使用包装层focusin打开菜单；后台focus()可能没有对应事件。适配补齐焦点及鼠标按下／释放，并回读实际值。

视频封面的实际入口是预览区域“编辑封面”，不是“设置封面”标题。裁剪、模板、贴纸、文字和滤镜标签分别核对激活状态；打开工具不等于已经应用或保存某个效果。

最小化时，已挂载弹层可能停留在透明入场过渡。适配只识别已确认的创作者popover／modal入场状态，标明transition_pending；普通隐藏节点与退出层仍不参与操作，不改平台CSS或抢前台。

## 受限测试稿

测试阶段 `creator_fixture` 只读取项目生成目录的固定素材并核对哈希，使用明确“测试勿发布”标题与固定正文；不允许任意文件、任意正文、删除、接受协议或正式提交。

先安装 `requirements-dev.txt` 并运行 `scripts/create_creator_test_fixtures.py`。生成物留在Git忽略目录，不附带实页账号、草稿ID、截图或诊断。

恢复测试稿须给出本次明确指定的草稿ID；先核对标题，再核对类型、完整标题和正文才恢复修改。其他草稿、后续人工改写或不一致媒体必须拒绝。操作测试稿需要用户对该次测试明确授权。

## 审核与指标回收

工作台“运营札记 → 回收最新后台数据”、HTTP的feedback与MCP的xhs_feedback使用同一实现，读取列表、状态与实际覆盖范围，保存观察时间。

全量分页请保持Chrome展开。最小化可能使平台只返回首批内容；分页不推进或时间用尽时返回非全量，不伪造剩余条目。未知曝光和公开状态保持未知；已发布也可能仅自己可见。

当前实页验证覆盖图文／视频／长文／播客的测试预览与存稿、可见范围切换与恢复、AI声明添加后清除、视频封面五类工具、现有笔记状态与指标回收。没有覆盖所有媒体的全部组件、最大上传规格、所有模板、跨设备恢复或新笔记正式提交后的审核等待。默认扩展的正式发布仍由使用者在Chrome逐篇核对并执行。
